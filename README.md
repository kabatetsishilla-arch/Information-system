# Information-system
software and hardware
. What is Hardware?

Hardware refers to the physical parts of a computer that we can see and touch.

Examples of hardware
Keyboard – used to enter information.
Mouse – used to point, select, and click.
Monitor – displays information on the screen.
CPU (Processor) – processes instructions and performs calculations.
RAM – temporarily stores information while the computer is running.
Hard disk/SSD – stores files and programs.
Printer – produces information on paper.
Speakers – produce sound.
Motherboard – connects the major components of a computer.
Types of hardware

1. Input devices
Used to enter data into a computer.
Examples: keyboard, mouse, scanner, microphone.

2. Output devices
Used to display or produce information.
Examples: monitor, printer, speakers.

3. Processing devices
Used to process data.
Example: CPU.

4. Storage devices
Used to store data and information.
Examples: SSD, hard disk, USB flash drive.

2. What is Software?

Software is a set of programs and instructions that tell a computer what to do.

Unlike hardware, software cannot be physically touched.

Examples of software
Microsoft Word
Google Chrome
Windows
Android
Adobe Photoshop
VLC Media Player
Antivirus programs
Types of software

1. System software
This controls and manages the computer's hardware and provides a platform for other programs.

Examples:

Windows
Linux
macOS
Android

2. Application software
This helps users perform specific tasks.

Examples:

Microsoft Word – writing documents
Microsoft Excel – calculations and spreadsheets
Google Chrome – browsing the internet
PowerPoint – creating presentations

3. Utility software
This helps maintain, protect, and manage a computer.

Examples:

Antivirus software
Disk cleanup tools
File compression software
Backup programs
Difference Between Hardware and Software
Hardware	Software
Can be seen and touched	Cannot be physically touched
Physical parts of a computer	Programs and instructions
Can be damaged physically	Can be corrupted or deleted
Examples: keyboard, CPU, monitor	Examples: Windows, Word, Chrome
Needs software to perform useful tasks	Needs hardware to run
